# منصة الاعتماد والتميز المؤسسي — مدارس دار الفرسان الأهلية (بنين) 🌟

منصة رقمية تفاعلية حديثة ومتكاملة لاستعراض وتوثيق شواهد وتقارير ومعايير الاعتماد المدرسي لمدارس دار الفرسان، مربوطة ومزامنة بالكامل مع **Google Drive**.

---

## 🚀 المميزات الرئيسية للمنصة:

* **التغطية الكاملة لمجالات ومعايير الاعتماد (100%):**
  * **4 مجالات رئيسية:** (الإدارة المدرسية، التعليم والتعلم، نواتج التعلم، البيئة المدرسية).
  * **11 معياراً معتمداً.**
  * **52 مؤشراً رقمياً شاملاً.**
* **فهرسة حية لـ Google Drive:**
  * **132 مجلداً فرعياً** موزعة بحسب المؤشرات.
  * **أكثر من 760 شاهد وتقرير رقمي** موثق.
* **إبراز تقارير الـ PDF المعتمدة أولاً:**
  * كل مؤشر يتصدره تقرير الـ PDF المعتمد مع زر معاينة سريعة داخل المنصة.
* **نظام الأكورديون والقوائم المنسدلة التفاعلية:**
  * استعراض مجلدات الشواهد الداعمة بنقرة واحدة، وتصفح محتويات أي مجلد مباشرة داخل الموقع.
* **عارض شواهد مدمج (In-App Document Viewer):**
  * معاينة ملفات PDF و Word وجداول Excel داخل نافذة منبثقة تفاعلية تدعم وضع ملء الشاشة والتحميل.
* **محرك بحث وتصفية فورية:**
  * بحث بالرقم (مثل `2-1-1-1`)، بالكلمات المفتاحية، أو حسب نوع المسار (المسار الأهلي، المسار العالمي).
* **لوحة إحصائيات ورسوم بيانية ذكية (Chart.js):**
  * رسوم بيانية توضح توزيع الشواهد ونسب الإنجاز ونوعية الملفات المرفوعة.

## 🌐 النشر والتشغيل المباشر عبر GitHub Pages:

يمكن نشر هذه المنصة مجاناً لتكون متاحة للجميع برابط مباشر عبر الإنترنت باتباع الخطوات التالية:

1. افتح المستودع على **GitHub**.
2. اذهب إلى تبويب **Settings** ➔ **Pages**.
3. في قسم **Branch**، اختر الفرع الرئيسي (`main` أو `master`) والمجلد (`/ (root)`).
4. اضغط **Save**، وخلال دقيقة سيظهر لك رابط الموقع الحي (Live URL) لمشاركته مباشرة مع اللجان والزوار!
